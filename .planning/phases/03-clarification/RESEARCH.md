Confirmed in skills/deep-interview/SKILL.md and related skill tests:

- project > user > default threshold resolution; default 0.20;
- Round 0 topology gate before scoring, 1-6 top-level components, deferrals;
- one-question-per-round default;
- global active component × dimension weakest targeting and sibling rotation;
- greenfield/brownfield weighted ambiguity formulas;
- re-score after every answer;
- Scout/explore repo facts before asking user decisions;
- Contrarian round 4+, Simplifier 6+, Ontologist 8+ if ambiguity > 0.30, each once;
- ambiguity stall within ±0.05 for 3 rounds activates Ontologist;
- early exit round 3+, soft warning round 10, hard cap round 20;
- stop/cancel/abort saves resumable state;
- SPEC crystallization remains execution-approval gated.

Hybrid already had the same ambiguity formulas, component-level max ambiguity, weakest-pair primitive, and canonical durable state. The port therefore extends those primitives rather than replacing them.
