# Bootstrap Research

Observed from pinned GSD Core:
- Codex roles are emitted as standalone agent TOMLs.
- The managed Codex config uses a bare agents table with max_depth = 1.
- Agent model pins are omitted by default so Codex can inherit the session model.
- spec-phase is scout-first and uses ambiguity/edge probes.
- execution is dependency/wave oriented and strongly evidence-gated.

Observed from pinned OMC:
- deep-interview has a Round 0 topology gate.
- clarity is tracked across goal, constraints, criteria, and brownfield context.
- role specialization includes architect, critic/reviewer, tester, security reviewer, and verifier.
- wiki provides ingest/query/lint concepts including stale, orphan, broken-link, oversized, and contradiction checks.
- team/runtime internals are much broader than needed for a Codex-first flat framework and are not ported wholesale.
