# Components

- Classifier: orchestration tier selection.
- Requirements Gate: OMC-style iterative clarification with Round 0 topology lock, Scout-first brownfield evidence, weakest component × dimension targeting, per-answer ambiguity recomputation, bounded challenge/stall handling, and approval-gated SPEC crystallization.
- Planning Council: researcher/planner/architect/auditor.
- Scheduler: dependencies + file ownership.
- State Store: atomic canonical state.
- Quality Lanes: tester/reviewer/security/verifier.
- Knowledge Synthesizer: durable documentation projection.
