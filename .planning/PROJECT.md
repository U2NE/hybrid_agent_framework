# Project

Build a Codex-first autonomous development framework preserving GSD-style thin orchestration, dependency-aware execution, file-backed state, and recovery while adding OMC-inspired requirements convergence, role-separated quality review, bounded fix loops, and a derived persistent wiki.

## Non-goals
- No GSD-vs-OMC-vs-hybrid benchmark harness.
- No recursive agent tree as default architecture.
- No second source of truth beside `.planning/`.
- No speculative hardcoded Codex model IDs.
