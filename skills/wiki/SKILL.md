# Wiki

.planning/ is canonical. .ai/wiki/ is a derived durable-knowledge projection.

After verified integration, update only durable:
- architecture
- decisions
- patterns
- debugging knowledge
- environment and setup
- testing
- current state

Do not copy routine implementation logs into the wiki.

Run wiki lint for:
- broken links
- orphan pages
- stale source projections
- oversized pages
- structural contradictions
