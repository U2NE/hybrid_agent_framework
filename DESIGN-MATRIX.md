The runtime layers have distinct meanings: **Runtime Event** records what actually happened; **Decision Provenance** records why Hybrid selected a control-flow action using bounded facts and policy metadata; **Actor Artifact** records what a specific worker did; **Audit** checks whether recorded decisions and actions agree. All four omit hidden reasoning. The lead alone writes central decisions/events; each worker API is structurally restricted to its own actor artifact, without claiming an OS sandbox against hostile processes. Attribution is observed, derived, or reported; reported worker metadata is valid bounded self-report but cannot by itself establish an observed action. Audit checks declared ownership and evidence links; it cannot detect unreported filesystem changes by itself.
